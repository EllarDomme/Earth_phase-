# 改提示词 / 调参数指南

> 给「不满意成品、想自己动手」的人。
> **不需要 AI 助手，改一个字符串就行。**

---

## 一、三道提示词在哪

整个流程里豆包被调用 **3 次**，提示词是三个 Python 常量：

| 轮次 | 文件 | 常量名 | 大概行号 | 作用 |
|---|---|---|---|---|
| 第 1 轮 | `doubao_polish.py` | `PROMPT` | 约 38 行 | 擦掉我们画的黑接缝线、修补断层的云 |
| 第 2 轮 | `doubao_polish.py` | `PROMPT_R2` | 约 44 行 | 清掉棕白色薄雾条带、消掉过亮光斑 |
| 第 3 轮 | `doubao_boost.py` | `PROMPT_BOOST` | 约 28 行 | 提清晰度（**不许改亮度**） |

**行号会随文件改动浮动，用常量名搜最稳**：

```powershell
# 在项目目录里
Select-String -Path doubao_polish.py,doubao_boost.py -Pattern "^PROMPT"
```

或者直接打开文件搜 `PROMPT`。

## 二、每种「不满意」该改哪一段

| 你看到的毛病 | 改哪 | 怎么改 |
|---|---|---|
| **还有细黑线没擦掉** | `PROMPT`（第 1 轮） | 强调「必须完全消除黑色细线，线两侧内容要接上」 |
| **黑线擦掉了但云变糊/断层** | `PROMPT`（第 1 轮） | 强调「只补被线挡住的窄条，不要重绘整片云」 |
| **表面有棕白色雾状竖条** | `PROMPT_R2`（第 2 轮） | 强调条带颜色和走向 |
| **海面有一块过亮** | `PROMPT_R2`（第 2 轮） | 强调「海面亮度要跟周围一致」 |
| **整张太软、不够锐** | `PROMPT_BOOST`（第 3 轮） | 强调锐度，**但不要删掉「亮度不可变」那句** |
| **地球被压暗了** | `PROMPT_BOOST`（第 3 轮） | 检查「【亮度不可变】…」这句是否还在 |

## 三、改的时候要注意

**① 第 3 轮那句「【亮度不可变】」不要删**

```python
# doubao_boost.py
PROMPT_BOOST = (
    "提高地球清晰度，加强锐度，……"
    "严格保持地球暗部原有的深黑，……"
    "【亮度不可变】地球的整体亮度与曝光必须与原图保持一致，"
    "不要压暗也不要提亮；只提高清晰度，不确定时保持原亮度不变。"
)
```

删了它，豆包会把地球压暗 **30% 以上**（实测 −34%）。
程序里还有 `match_disc()` 兜底，但那是事后补救，不如一开始就说清楚。

**② 提示词是「拼接字符串」，可以只改一小段**

```python
PROMPT = ("只清除笔直模糊条带和线性遮挡，"
          "黑线两边的云层有不自然的，……"     # ← 改这一句就行
          "其他不改真实云系、海洋纹理、陆地轮廓、地球弧面和原始光照；"
          "……")
```

**③ 改完用同一个日期重跑，才知道差别**

```powershell
.\run.cmd 2009-06-21
.\verify.cmd 2009-06-21
```

> **一次重跑 = 3 次豆包额度**。想省额度就先改一处、只跑一个日期对比。

## 四、不是提示词的问题，是参数问题

有些「不满意」跟提示词无关，是渲染/拼图参数：

| 想要的效果 | 改哪 | 参数 |
|---|---|---|
| 地球大一点 / 小一点 | `compose_moon.py` | `--earth-pct`（默认 0.36） |
| 地球位置左右移 | `compose_moon.py` | `--cx`（默认 0.50） |
| 地球上下移 | `compose_moon.py` | `--cy`（默认 0.31） |
| 月面亮一点 | `compose_moon.py` | `--moon-gain`（默认 0.65） |
| 整体亮一点 | `lighting.py` | `EXPOSURE`（默认 1.7） |
| 晨昏线更柔和 | `lighting.py` | `term_w`（默认 0.08） |
| 大气弧更明显 | `lighting.py` | `ARC_A` / `ARC_A2` |
| 夜面更亮一点 | `lighting.py` | `NIGHT_SRGB`（默认 3.5） |

**改这些不用花豆包额度**——如果只涉及光照，可以从 `v2\_bak_*` 重新打光：

```powershell
# 注意：这是进阶用法，需要一点 Python 基础
python -c "import lighting; from PIL import Image; lighting.apply_lighting(Image.open(r'v2\_bak_uni_<日期>_月面_提升_1920x1280.png').convert('RGB'), '<日期>', <UTC>).save(r'成品\test.png')"
```

## 五、改完怎么看效果（人工三看）

`verify.cmd` 的 PASS **只代表技术上没坏**（几何对、曝光对），不代表好看。交付前还要人眼看三处：

| # | 看什么 | 不合格的样子 |
|---|---|---|
| 1 | **看接缝** | 地球表面有笔直或弯曲的**细黑线**、棕白色雾带 |
| 2 | **看云系** | 云被"重绘"成不自然的样子、出现重复纹理、陆地轮廓变形 |
| 3 | **看明暗** | `_月面_提升` 和 `_月面` 两张**亮度差很多**（说明豆包改了曝光） |

三看都过关，才算能交付。

---

## 七、一句话原则

> **提示词只负责「让豆包听懂要干嘛」，不负责「保证结果」。**
> 真正的保险在代码里：尺寸校验、md5 对账、亮度还原、失败中止。
> 所以**改提示词是安全的**——最坏情况是重跑一次，不会产出坏图。
